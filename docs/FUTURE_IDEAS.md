# Future directions — an invitation, not a roadmap

The best next feature is whatever removes genuine friction for **your** team. A human–AI pair might explore:

- **Keyboard-first navigation:** configurable shortcuts, command palette, recent destinations.
- **Course and user favourites:** local bookmarks to commonly used pages, with privacy-conscious storage.
- **Contextual links:** shortcuts from a course, profile, or participant page to frequently needed adjacent views.
- **Accessible interface options:** keyboard navigation through search results, better focus handling, high contrast, screen-reader labels, localisation.
- **Configurable modules:** turn features on/off and set positions without editing source code.
- **Better index sources:** approved exports, supported APIs, pagination handling, staleness warnings, and explicit refresh.
- **Workflow-specific helpers:** enrolment checks, reporting navigation, or repetitive admin tasks—only after a separate permissions and safety review.
- **Shared recipes:** community-contributed prompts and inspection procedures for different Moodle versions/themes.

Not every idea should become a feature. Prefer a small improvement that demonstrably saves time over a sprawling interface. Validate each new behaviour in the local environment before sharing it.
