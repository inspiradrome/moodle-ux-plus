# Generic examples

This folder intentionally contains **small patterns**, not a turnkey production userscript. They illustrate reusable behaviour without assuming a particular Moodle URL or DOM.

- [`auto-field.js`](auto-field.js): email-shape detection, explicit override, and hint text.
- [`course-search.js`](course-search.js): in-memory course ranking with no network requests or storage.

Your AI assistant should inspect your Moodle installation and build an integration that uses only verified local selectors and approved data sources.
